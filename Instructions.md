Instructions for BRM-5-Importer

What you need:
- BRM5Importer.exe        (preferably the latest Version)
- a .txt File containing a list of commands to Import



How to use:
- Open BRM5Importer.exe
- wait for the File select window to open, and select your File
- Enter the world the Trigger should be Created in / Enter the world your trigger is in*                                            *if you are using a file from certain programs these steps do not apply
- Enter the Name of the Trigger*
- Select if a new Trigger should be Created*
- select your Roblox window and move the mouse over the console, then press "Alt"                                                   (over the part of the console where commands are entered)
- once the Program is complete it will stop sending commands, and after pressing any button will close itself
