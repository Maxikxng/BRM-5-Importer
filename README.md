# BRM-5-Importer
Import a list of commands from .txt files into the Realtime Game Editor of Blackhawk Rescue Mission 5 automatically.

Usage explained [here](https://github.com/Maxikxng/BRM-5-Importer/blob/main/Instructions.md).

Works Best on Files exported from m_smi´s [Command Editor](https://triple-alt.github.io/brm5-command-editor/editor.html).
also compatible with files from TyllerLob´s [Compiler](https://github.com/TyllerTheGamer/compiledrgescript).

Made in Python 3.
